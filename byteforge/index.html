A real IDE
in your pocket

Not a simulator.

ByteForge carries OpenJDK 25 inside the app. The real javac compiles your code, and a real JVM runs it on your phone’s processor. No remote compiler, no Termux, no root, and no computer needed.

01

Java 25, for real

Records, sealed types, pattern matching, text blocks, var, and the new compact source files with a simple main. The compiler stays loaded between builds, so rebuilding is quick.

02

Made for thumbs

Syntax highlighting, undo and redo, find and replace, and a key bar for the brackets and symbols your keyboard hides. Pick from 7 editor themes, from GitHub Light to Dracula and Nord, and set your font size.

03

Mistakes, caught early

As you type, ByteForge checks your code: red errors, amber warnings, and blue hints, right in the editor. It also spots strings compared with ==, empty catch blocks, unused imports, and unused variables.

04

A console that talks back

Programs that read input work like a terminal: type a line and press Enter. Set program arguments and a working folder, choose which main class to run, and copy the output.

05

Swing and AWT windows

Frames, buttons, text fields, dialogs, and Graphics2D drawings open inside the app with a modern FlatLaf look. Tap, type, scroll, zoom, and maximize or minimize windows.

06

Projects that keep

Multi-file projects with packages and folders, 6 starter templates, and import and export as ZIP or .java files. Unsaved edits are recovered if the app closes.

More screen,
more room

Turn your phone sideways or open ByteForge on a tablet, and your files, code, and console fit side by side.

A little more to know

What you need

Android 10 or newer on a 64-bit phone or tablet. The first compile sets up the Java runtime once, which takes a little while. JavaFX, sound, and OpenGL aren’t supported.

Your code stays yours.

ByteForge has no internet access, and your programs run sealed in Android’s sandbox, away from your other projects. Learn how ByteForge handles your code and projects.
